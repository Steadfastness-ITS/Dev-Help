# 💻 Monaco Code Editor - VS Code Integration

A complete Monaco Editor (VS Code editor) integration for LibreChat.

## 📦 Components

### 1. **MonacoEditor** - Core Editor Component
```tsx
<MonacoEditor
  value={code}
  language="javascript"
  onChange={setCode}
  height="400px"
  minimap={true}
  lineNumbers="on"
/>
```

**Features:**
- Syntax highlighting for 50+ languages
- IntelliSense autocomplete
- Error detection
- Code formatting
- Diff editor mode
- Dark/light themes
- Minimap
- Find/replace

### 2. **CodeEditorDialog** - Modal Editor
```tsx
<CodeEditorDialog
  open={open}
  onOpenChange={setOpen}
  title="Edit Code"
  defaultCode="const x = 42;"
  language="typescript"
  onSave={handleSave}
/>
```

**Features:**
- Full-screen mode toggle
- Copy to clipboard
- Download code
- Format code
- Save/cancel actions

### 3. **CodeEditorPanel** - Panel with Toolbar
```tsx
<CodeEditorPanel
  defaultLanguage="javascript"
  onExecute={executeCode}
  height="600px"
  showToolbar={true}
  title="Code Playground"
/>
```

**Features:**
- Language selector
- Toolbar with actions
- Execute button
- Settings panel
- Copy/download/format
- Reset code

## 🔧 Configuration

Customize via props:

```tsx
<MonacoEditor
  value={code}
  language="typescript"
  theme="vs-dark" // vs-dark, vs-light, hc-black
  readOnly={false}
  minimap={true}
  lineNumbers="on"
  fontSize={14}
  wordWrap="on"
  autoFormat={true}
  options={{
    // Any Monaco editor option
    tabSize: 2,
    insertSpaces: true,
    // ... 100+ more options
  }}
/>
```

## 🌟 Pro Tips

- Use `Cmd/Ctrl + F` for find
- Use `Cmd/Ctrl + Shift + F` for find/replace
- Use `Alt + Click` for multi-cursor
- Use `Cmd/Ctrl + /` to toggle comments
- Use `Shift + Alt + F` to format code
- Use `F12` to go to definition
- Use `Shift + F12` for find references
